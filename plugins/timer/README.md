# Timer

A shared timer for the voice room: a focus session or a short break, with everyone on the same countdown.

## How to use it

- Pick **Focus** or **Short break**.
- Anyone in the room can start, pause or reset the timer.
- While the timer is **paused**, the centre of the dial becomes the duration picker: hours (up to 99), minutes and seconds, each with arrows above and below. You can also type the numbers. Changes apply automatically after a moment, there is no Apply button.
- Each mode remembers its last duration on your device. Switching mode uses that value.
- When the countdown reaches zero every client rings a bell. The first tap on the timer unlocks audio: browsers keep sound blocked until a gesture.

The countdown follows the server clock, so a late joiner lands on the same second.

Limits: one instance per room, and up to three activities can run at once.
